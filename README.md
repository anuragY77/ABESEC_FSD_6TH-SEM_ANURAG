## 📖 About This Repository

This is a **day-wise training log** from my Full Stack Development coursework — not a single project, but a collection of focused exercises covering core Node.js and JavaScript concepts, building up from async fundamentals to a small file-based CRUD system.

<br>

## 🗓️ Day-Wise Breakdown

<table>
<tr><th>Day</th><th>Topic</th><th>What's Covered</th></tr>

<tr>
<td align="center">📅 1</td>
<td><b>Promises & Async/Await</b></td>
<td>JavaScript Promise objects, <code>resolve</code>/<code>reject</code>, async functions, and fetching live data from an external API (<code>fetch</code> + <code>fakestoreapi.com</code>)</td>
</tr>

<tr>
<td align="center">📅 2</td>
<td><b>Node.js File System (Sync vs Async)</b></td>
<td>File read/write/append operations using both <code>fs</code> (sync) and <code>fs/promises</code> (async) APIs, with error handling</td>
</tr>

<tr>
<td align="center">📅 3</td>
<td><b>Node.js fs (Advanced) + OS Module</b></td>
<td>Directory operations (<code>readdir</code>, <code>mkdir</code>, <code>rmdir</code>), file stats (size, type), and reading system info (CPU architecture, memory) via the <code>os</code> module</td>
</tr>

<tr>
<td align="center">📅 4</td>
<td><b>Mini CRUD System</b></td>
<td>Built Create/Read/Update/Delete operations on a JSON file acting as a lightweight student database — no real DB, just file-based persistence</td>
</tr>

<tr>
<td align="center">📅 5</td>
<td><b>Login & Registration Logic</b></td>
<td>Basic authentication flow — checking credentials against a JSON user store, registration with duplicate-user validation</td>
</tr>

<tr>
<td align="center">📅 6</td>
<td><b>DOM Manipulation Mini-Project</b></td>
<td>A small frontend page with tab-based section switching and an auto-rotating image slider using vanilla JS, HTML, and CSS</td>
</tr>

</table>
